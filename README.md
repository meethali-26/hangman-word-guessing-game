
# Hangman Word Guessing Game

## About
This is a simple word guessing game developed using Python.

## Features
- Random word selection
- Six incorrect attempts allowed
- Letter-by-letter guessing
- Displays the hidden word
- Win and lose messages
- Input validation

## Technology Used
- Python
- Random module

## How to Run
1. Install Python.
2. Open the project folder.
3. Open Command Prompt in that folder.
4. Run:

python hangman.py
